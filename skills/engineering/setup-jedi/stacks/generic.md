# Other stack

Use the stack's official create command; ask the user for it if you do not know it. Apply only the core: `AGENTS.md` (omit `Camadas`), glossary, `docs/agents/testing.md`.

Pick a test runner the community uses for the language, wire the full-suite command (parallel if it exists) into `AGENTS.md`, and add one passing smoke test. Propose a complexity linter and a layers check if the language has them; the user decides.

Before using a command you did not run yourself, run it once in a scratch folder.
